1. 新增模块：chan/view_loader.py

在 chan/ 目录下新建 view_loader.py（只读，不写 DB），实现：

from dataclasses import dataclass
from datetime import datetime, date
from typing import List

import pandas as pd

from .types import Bi, Segment, Center, Signal, ChanResult
from db import get_engine
from sqlalchemy import text

@dataclass
class ChanViewData:
    kline: pd.DataFrame       # datetime, open/high/low/close/volume
    bis: List[Bi]
    segments: List[Segment]
    centers: List[Center]
    signals: List[Signal]

) -> pd.DataFrame:
    """
    从 stock_kline 读取指定 code+freq+时间窗口的 K 线。
    要求返回列至少包含: datetime, open, high, low, close, volume。
    """
    ...


def load_chan_structures(
    ts_code: str,
    freq: str,
    start: datetime,
    end: datetime,
) -> ChanResult:
    """
    从 stock_chan_bi / stock_chan_segment / stock_chan_center / stock_chan_signal
    读取指定 code+freq+时间窗口的缠论结构，组装为 ChanResult。
    """
    ...


def get_chan_view_data(
    ts_code: str,
    freq: str,
    start: datetime,
    end: datetime,
) -> ChanViewData:
    """
    统一入口：返回画图所需的全部数据。
    """
    kline = load_kline(...)
    chan = load_chan_structures(...)
    return ChanViewData(
        kline=kline,
        bis=chan.bis,
        segments=chan.segments,
        centers=chan.centers,
        signals=chan.signals,
    )


实现要求：

load_kline：

从 stock_kline 读取 ts_code, freq 匹配，datetime between start and end；

按 datetime 升序排序；

如果没有数据，返回空 DataFrame，不抛异常。

load_chan_structures：

从四张 chan 表读取当前窗口内的记录；

按你之前 chan/types.py 里的 dataclass 构造 Bi/Segment/Center/Signal；

ChanResult 内的列表可以是“窗口内全部元素”，不必精确裁边；

如果某张表在该窗口内为空，对应列表就是空。

该模块只读，不写 DB。
