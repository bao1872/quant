一、总体要求（必须遵守）

只有一套关键位：CompositeLevel 列表是全局唯一的。

周线、日线、60 分钟（以及 30/15/5 分钟）图 全部共用这一套 综合关键位；

各周期只能改变 K 线的数据，不允许改变关键位集合。

画图时只使用 CompositeLevel。

默认模式下 禁止 再画单周期 raw OB / BOS / swing level 等横线；

只允许画 TopN 条综合关键位线。

关键位线型极简：

颜色统一为 OB 蓝色（你当前使用的蓝色即可）；

只用线型区分“周主导 / 日主导 / 60m 主导”，不得再引入其它线型和颜色。

Trae 必须自己做两层验证：

分析层：检查 CompositeLevel 数据是否自洽（strength、dominant_tf、total_strength 公式正确）；

UI 层：检查周 / 日 / 60m 三个周期使用的是完全同一套关键位，并且线条数量与 TopN 要求一致。

2.1 数据结构（必须具备这些字段）

在关键位计算模块中（例如 analysis/multi_tf_key_levels.py），确认或新增以下 dataclass：

from dataclasses import dataclass
from typing import List, Literal

Freq = Literal["W", "D", "60m"]
Kind = Literal["support", "resistance"]

@dataclass
class SingleTFLevel:
    price: float
    kind: Kind            # 该周期视角下支撑/压力
    freq: Freq            # "W" / "D" / "60m"
    strength_tf: float    # 单周期强度
    touch_count: int
    avg_reaction: float
    span_bars: int
    role_switch_count: int

@dataclass
class CompositeLevel:
    price: float
    kind: Kind            # 多周期综合后的支撑/压力
    total_strength: float # 文档中的 total_strength(K)
    strength_W: float
    strength_D: float
    strength_H1: float
    dominant_tf: Freq     # "W" / "D" / "60m"，贡献最大的周期
    members: List[SingleTFLevel]


禁止 再额外维护第二套关键位结构（例如另一种“OBLevel”列表），所有综合关键位必须统一映射到 CompositeLevel。

2.3 多周期聚类 + total_strength + dominant_tf

实现统一聚类函数：

def cluster_levels_with_hdbscan(
    levels: list[SingleTFLevel],
    *,
    eps_pct: float = 0.005,
    min_cluster_size: int = 2,
    allow_noise_as_singleton: bool = True,
) -> list[CompositeLevel]:
    ...


聚类与合成要求：

聚类维度只使用价位：
HDBSCAN 的输入特征必须以 price 为主，距离使用相对价差（受 eps_pct 控制）。

对每个聚类簇 K，构造 CompositeLevel：

price：簇内 price 的 strength_tf 加权平均；

周 / 日 / 60m 贡献：

strength_W  = sum(l.strength_tf for l in members if l.freq == "W")
strength_D  = sum(l.strength_tf for l in members if l.freq == "D")
strength_H1 = sum(l.strength_tf for l in members if l.freq == "60m")


total_strength 必须按文档权重计算：

W_W, W_D, W_H = 4.0, 3.0, 2.0
total_strength = W_W*strength_W + W_D*strength_D + W_H*strength_H1


dominant_tf：
strength_W/D/H1 三者中数值最大的那个对应的周期；

kind：
按簇内 SingleTFLevel.kind 和 strength_tf 加权投票，合力偏向 support → support，否则 resistance。

3.2 关键位过滤：只画 TopN 条

在绘制主图前，实现统一过滤函数：

def filter_levels_for_plot(
    composite_levels: list[CompositeLevel],
    y_min: float,
    y_max: float,
    max_lines: int = 10,
) -> list[CompositeLevel]:
    # 1) 先按可见 Y 轴范围过滤
    in_view = [
        l for l in composite_levels
        if (y_min * 0.9) <= l.price <= (y_max * 1.1)
    ]
    if not in_view:
        return []

    # 2) 按 total_strength 由高到低排序
    in_view.sort(key=lambda l: l.total_strength, reverse=True)

    # 3) 只取前 max_lines 条
    return in_view[:max_lines]


在 plot_main_chart 中 只能 使用该函数得到要画的线：

levels_for_plot = filter_levels_for_plot(composite_levels, y_min, y_max, max_lines=10)


禁止再按“周主导一组、日主导一组、60m 一组分别 TopN”之类的方式叠加多套线。
